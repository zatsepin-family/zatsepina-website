# Project images

Drop your architecture photographs into this folder.

## Naming

Match the filename used in `index.html`. By default the site references:

- `project-01.jpg`
- `project-02.jpg`
- `project-03.jpg`

If you add more projects, copy an existing `<article class="project">` block in `index.html` and update the image path, the project number, and the writeup.

## Recommended specs

- **Format**: `.jpg` (photos) or `.webp` (smaller files)
- **Aspect ratio**: 3 : 2 landscape works best — the figure block is sized to match
- **Resolution**: ~2400 px on the long edge is plenty for retina displays
- **File size**: aim for under ~600 KB per image (use [Squoosh](https://squoosh.app) or similar)

## Tips

- Use consistent orientation across projects if possible (all landscape, or all square).
- Alt text matters — when you replace an image, also update the `alt` attribute in the HTML.
- If a filename needs spaces, either replace them with `-` or use `%20` in the HTML `src`.
